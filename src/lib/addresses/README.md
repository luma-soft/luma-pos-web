# Vietnamese administrative address data

`vietnam-admin.json` contains 34 province-level units and 3,321 commune/ward-level units, including their official administrative codes and approximate area-center coordinates.

Names and coordinates are projected from [Open Admin Data's Vietnam administrative divisions dataset](https://openadmindata.org/api/vn/), licensed under [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/). The data follows Vietnam's 2025 administrative reorganization. The government publishes the current list of [3,321 commune-level units](https://xaydungchinhsach.chinhphu.vn/danh-sach-3321-don-vi-hanh-chinh-cap-xa-tai-34-tinh-thanh-sau-sap-xep-sap-nhap-119250710102358656.htm) and [codes for the 34 provinces and cities](https://xaydungchinhsach.chinhphu.vn/bang-danh-muc-va-ma-so-cua-34-tinh-thanh-moi-cac-don-vi-hanh-chinh-cap-xa-moi-11925070418263625.htm).

Ward coordinates are approximate centroids and are used only when street-address geocoding cannot resolve a result inside the selected ward and province.
